# GPT to Notion Serverless API (Vercel)

This project lets GPT-4 POST structured summaries to a Make Webhook, which then saves them into Notion.

## Setup

1. Fork this repository to your GitHub account.
2. Import the repository into Vercel.
3. Set the environment variables:
   - `OPENAI_API_KEY`
   - `WEBHOOK_URL`
4. Deploy and use your Vercel endpoint (e.g. `/api`)
